No login is needed: the app has no account. Open it, choose "France" or "Suisse", then use the Explorer tab.

Dynamic code (engine updates), new in 0.7.1: the maths exercises come from an exercise engine written in JavaScript and CSS (no native code, no DEX, no .so). The app bundles one engine and, so that students get fixed exercises without an app update, it can download a newer one from our own repository over HTTPS: https://forge.apps.education.fr/coopmaths/mathalea-mobile/-/raw/main/releases/moteur/ . The announcement file is signed with our Ed25519 key; the app checks the signature, the size, the SHA-256 of the archive and the interface version before using it, otherwise it keeps the bundled engine. A new engine is activated at the next launch, never during an activity. Engine updates only add or fix maths exercises: they never change the app's features, show ads or collect data. The engine version is shown in Settings ("Réglages").

What the engine can reach: it runs in the app's WebView like the rest of the interface. It is given no extra native interface and no permission of its own: the app declares only Internet and camera (camera used only to scan the QR code of a class link, after the system permission prompt). The app's own bridge (Tauri) only exposes its local progress database, the system file save dialog and HTTPS requests; no contacts, location, SMS, accounts or device identifiers. Only code signed by us is ever loaded.

Play support (case of 12 November 2026) confirmed that JavaScript and CSS downloaded into a WebView under these conditions comply with the Device and Network Abuse policy.
