## MathALÉA 0.6.0

L'application devient celle des élèves. Les enseignants préparent leurs
parcours sur le site MathALÉA (page « Parcours pour l'application ») et les
déposent dans un dossier de leur drive, comme avant.

### Nouveautés

- Scanner, en haut de l'accueil : le QR code d'une classe (le lien du
  dossier de l'enseignant, avec `?classe=`) ajoute le dossier et choisit la
  classe ; le QR code d'une session partagée ouvre directement la session.
  Ces QR codes sont maintenant courts et se lisent bien à la caméra.
- Session partagée créée par n'importe qui, depuis la page d'un parcours
  (« Autres actions », « Session partagée ») : un code et son QR code. Un
  élève qui scanne le QR code sans avoir la classe la reçoit en même temps.
- Signaler un problème dans un parcours (bug, erreur, contenu inapproprié) :
  un mail à l'équipe MathALÉA s'ouvre avec le parcours dedans ; le parcours
  peut aussi être caché. Contact dans les Réglages.
- Explorer France : deux premiers parcours à ceintures (additionner et
  soustraire des relatifs en 5e, fractions en 4e).
- Accueil sans dossier : bouton « Scanner le QR code de ma classe ».

### Retiré

- Le mode enseignant de l'application (bibliothèque, éditeur, classes,
  sessions de classe, QR codes des réponses). Une bibliothèque préparée dans
  l'application reste sur l'appareil : Réglages, « Exporter ma
  bibliothèque », puis reprise sur le site MathALÉA. Les QR codes de classe
  déjà imprimés restent lisibles.
