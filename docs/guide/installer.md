# Installer l'application

[Retour aux guides](index.md)

## Android

### Par le Play Store

L'application arrive bientôt sur le Play Store. En attendant, elle est en test. Pour faire partie des bêta-testeurs, écrivez à contact@coopmaths.fr avec l'adresse mail de votre compte Google. Vous recevrez un lien d'inscription.

Une fois inscrit, ou une fois l'application publiée :

1. Ouvrez le Play Store et cherchez « MathALÉA », ou suivez [ce lien](https://play.google.com/store/apps/details?id=fr.coopmaths.mathalea).
2. Touchez « Installer ».

Elle se met ensuite à jour comme les autres applications. Chaque semaine, une nouvelle version apporte les derniers exercices du site.

En attendant, tout se fait aussi sur ordinateur (voir plus bas).

### Sans le Play Store (fichier APK)

Pour un appareil sans Play Store, ou pour essayer une version avant tout le monde.

1. Sur le téléphone, ouvrez la [dernière version](https://forge.apps.education.fr/coopmaths/mathalea-mobile/-/releases/permalink/latest).
2. Touchez `MathALEA-…-android-arm64.apk`. C'est le bon fichier pour presque tous les téléphones récents. Sur un vieux téléphone, prenez `…-android-armv7.apk`.
3. Ouvrez le fichier téléchargé. Android demande d'autoriser l'installation depuis votre navigateur. Acceptez, puis touchez « Installer ».

Une application installée comme ça ne se met pas à jour par le Play Store. Pour passer à la version du Play Store, faites d'abord une sauvegarde dans les Réglages (« Exporter une sauvegarde »), désinstallez, installez l'autre version, puis « Restaurer une sauvegarde ».

## Ordinateur

Sur la [dernière version](https://forge.apps.education.fr/coopmaths/mathalea-mobile/-/releases/permalink/latest), prenez le fichier qui correspond à votre ordinateur.

- **Windows** : `…-windows-setup.exe`. Double-clic. Si Windows affiche un avertissement, cliquez sur « Informations complémentaires » puis « Exécuter quand même ».
- **Mac récent (puce Apple)** : `…-macos-apple-silicon.dmg`. Glissez l'application dans Applications. La première fois, clic droit puis « Ouvrir ».
- **Mac Intel** : `…-macos-intel.dmg`. Pareil.
- **Linux** : `.deb`, `.rpm` ou `.AppImage`, selon votre distribution.

## iPhone et iPad

Pas encore disponible. Apple n'autorise l'installation que par l'App Store, ou par TestFlight pour les tests. L'application y arrivera d'abord en test.

Quand le lien de test sera là :

1. Installez **TestFlight** depuis l'App Store. C'est une application gratuite d'Apple.
2. Sur l'iPhone ou l'iPad, ouvrez le lien de test de MathALÉA.
3. Touchez « Accepter » puis « Installer ».

Une version de test dure 90 jours. TestFlight propose la suivante tout seul.
