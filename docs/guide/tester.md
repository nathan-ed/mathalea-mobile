# Tester avec des collègues

[Retour aux guides](index.md)

Merci de prendre un moment pour essayer l'application. Une demi-heure suffit pour faire le tour ; la [Prise en main](prise-en-main.md) guide pas à pas.

## Installer

- Android : installez le fichier APK, [MathALÉA 0.6.0 pour Android](https://forge.apps.education.fr/coopmaths/mathalea-mobile/-/raw/main/releases/v0.6.0/MathALEA-0.6.0-android-arm64.apk). Marche à suivre : [Installer l'application](installer.md).
- Ordinateur (Windows, Mac ou Linux) : la marche à suivre est dans [Installer l'application](installer.md).
- iPhone et iPad : la version de test s'installe avec un ordinateur, pas à pas : [Installer sur iPhone ou iPad](iphone.md).

## Ce qu'on peut essayer

1. Ajouter le dossier de démonstration et faire un parcours ([Découvrir](decouvrir.md)).
2. Créer un parcours de votre niveau sur le site MathALÉA, le donner à une classe et publier ([Créer sur le site](creer-sur-le-site.md)).
3. Déposer le fichier dans un dossier partagé de votre drive, puis ajouter ce dossier sur un autre téléphone ou avec un élève ([Côté élève](eleves.md)).
4. Essayer les paliers ou les ceintures : un seuil de réussite, une pause, une ressource pour revoir.
5. Modifier le parcours, republier, et vérifier que la nouvelle version arrive chez l'élève.
6. Créer une session partagée depuis la page d'un parcours, afficher son QR code et le scanner depuis un autre téléphone ([Sessions](sessions.md)).
7. Terminer deux parcours, puis revenir le lendemain : la tuile « Révisions » propose une courte séance ([Révisions](revisions.md)).

## Nous dire ce qui ne va pas

Pour chaque remarque, écrivez à contact@coopmaths.fr en précisant :

- le téléphone ou l'ordinateur, et sa version d'Android, de Windows… ;
- la version de l'application (Réglages, en bas, « À propos ») ;
- ce que vous avez fait, ce que vous attendiez et ce qui s'est passé ;
- une capture d'écran si possible.

Vos idées sont aussi les bienvenues, par exemple sur ce qui manque, ce qui n'est pas clair ou ce qui prend trop de temps.
