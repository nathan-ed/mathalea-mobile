# Tester avec des collègues

[Retour aux guides](index.md)

Merci de prendre un moment pour essayer l'application. Une demi-heure suffit pour faire le tour.

## Installer

- Android : en attendant le Play Store, écrivez à contact@coopmaths.fr avec l'adresse mail de votre compte Google pour recevoir le lien de test, ou installez le fichier APK. Tout est expliqué dans [Installer l'application](installer.md).
- Ordinateur : Windows, Mac ou Linux, voir [Installer l'application](installer.md).
- iPhone et iPad : la version de test TestFlight arrive bientôt. Pour les curieux, une installation avec un ordinateur est possible dès maintenant, voir [Installer l'application](installer.md).

## Ce qu'on peut essayer

1. Charger les parcours de démonstration et en faire un comme un élève ([Découvrir](decouvrir.md)).
2. Créer un parcours de votre niveau, le donner à une classe et publier ([Créer un parcours](creer.md)).
3. Mettre le fichier dans un dossier partagé de votre drive, puis l'ajouter depuis un autre téléphone, ou avec un élève ([Côté élève](eleves.md)).
4. Essayer les paliers ou les ceintures : un seuil de réussite, une pause, une ressource pour revoir.
5. Modifier le parcours, republier, et vérifier que la nouvelle version arrive chez l'élève.

## Nous dire ce qui ne va pas

Pour chaque remarque, écrivez à contact@coopmaths.fr en précisant :

- le téléphone ou l'ordinateur, et sa version d'Android, de Windows… ;
- la version de l'application (Réglages, en bas, « À propos ») ;
- ce que vous avez fait, ce que vous attendiez et ce qui s'est passé ;
- une capture d'écran si possible.

Les idées sont bienvenues aussi : ce qui manque, ce qui n'est pas clair, ce qui prend trop de temps.
