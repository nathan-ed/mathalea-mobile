# Installer la version de test sur iPhone ou iPad

[Retour aux guides](index.md)

MathALÉA n'est pas encore sur l'App Store. Vous pouvez déjà l'essayer sur votre iPhone ou votre iPad en l'installant vous-même avec un ordinateur. Comptez un quart d'heure la première fois.

## Ce qu'il faut

- Un ordinateur Windows ou Mac, et le câble de l'iPhone.
- Un identifiant Apple (celui de l'iPhone convient, un compte gratuit suffit).
- Le logiciel gratuit [Sideloadly](https://sideloadly.io), qui installe l'application sur l'iPhone.

Une application installée ainsi reste **7 jours**. Ensuite, elle ne s'ouvre plus : refaites l'étape 4 (deux minutes), vos parcours et vos résultats sont gardés. Un identifiant Apple gratuit installe au plus trois applications de cette façon.

## 1. Télécharger l'application

Sur l'ordinateur, ouvrez la [dernière version](https://forge.apps.education.fr/coopmaths/mathalea-mobile/-/releases/permalink/latest) et téléchargez le fichier `MathALEA-…-ios-non-signee.ipa`.

## 2. Installer Sideloadly

Téléchargez Sideloadly sur [sideloadly.io](https://sideloadly.io) et installez-le.

Sous Windows, il faut aussi **iTunes** et **iCloud**, téléchargés depuis le site d'Apple (pas ceux du Microsoft Store) : Sideloadly s'en sert pour parler à l'iPhone.

## 3. Brancher l'iPhone

Branchez l'iPhone à l'ordinateur avec le câble. Sur l'iPhone, touchez « Se fier à cet ordinateur » et tapez votre code.

## 4. Installer MathALÉA

1. Ouvrez Sideloadly. Votre iPhone apparaît en haut.
2. Glissez le fichier `.ipa` dans la fenêtre.
3. Saisissez votre identifiant Apple, puis cliquez sur « Start ».
4. Tapez votre mot de passe Apple, et le code de validation si Apple en envoie un. Ils servent seulement à Apple pour signer l'application.

Au bout d'une minute, Sideloadly affiche « Done ».

## 5. Autoriser l'application sur l'iPhone

1. Ouvrez Réglages, Général, « VPN et gestion de l'appareil ».
2. Touchez votre identifiant Apple, puis « Faire confiance ».
3. Sur iOS 16 et plus, activez aussi le mode développeur : Réglages, « Confidentialité et sécurité », « Mode développeur ». L'iPhone redémarre ; confirmez « Activer ».

L'icône MathALÉA est sur l'écran d'accueil. Vous pouvez commencer : [Prise en main](prise-en-main.md).

## Au bout de 7 jours

Rebranchez l'iPhone, ouvrez Sideloadly, glissez le fichier `.ipa` (ou celui d'une version plus récente) et cliquez sur « Start ». Les étapes 2, 3 et 5 ne sont plus nécessaires.

## Si quelque chose bloque

- **L'iPhone n'apparaît pas dans Sideloadly** : déverrouillez-le, rebranchez le câble, et vérifiez sous Windows qu'iTunes reconnaît l'iPhone.
- **« Impossible de vérifier l'app »** sur l'iPhone : faites l'étape 5.
- **L'application ne s'ouvre plus** : les 7 jours sont passés, refaites l'étape 4.
