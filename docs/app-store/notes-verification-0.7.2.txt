Version 0.7.2: exercise engine updates (please read)

MathALÉA is a free, open-source maths exercise generator written by a non-profit association of maths teachers (CoopMaths). Its source is public: https://forge.apps.education.fr/coopmaths/mathalea . It changes every day: 795 merge requests were merged in the last 30 days, on each of those 31 days, mostly new exercises and fixes reported by teachers, for example a missing letter on the maths keyboard (https://forge.apps.education.fr/coopmaths/mathalea/-/merge_requests/10188) or a misplaced answer line on phones (https://forge.apps.education.fr/coopmaths/mathalea/-/merge_requests/10189). Until now the iOS app could only receive such fixes through a new App Store version, so students kept known errors for weeks.

Why it matters to students: a wrong correction teaches a student that a right answer is wrong. Fixing it within a day instead of weeks directly protects their learning. CoopMaths is funded by the French Ministry of Education, and MathALÉA is used every day by teachers in France and French-speaking Switzerland: our reputation with the Ministry, and the trust of teachers and parents, rest on exercises that are correct and safe. That is also why every update is public, reviewed by teachers before it is merged, and signed by us.

What changes in 0.7.2: the app can download a newer build of its exercise engine. The engine is JavaScript and CSS only, run by WebKit in the app's WKWebView (Developer Program License Agreement 3.3.1(B)); it contains no native code. It is published by us in the app's own open-source repository over HTTPS: https://forge.apps.education.fr/coopmaths/mathalea-mobile/-/tree/main/releases/moteur . The announcement file is signed with our Ed25519 key; the app checks the signature, the size and the SHA-256 of the archive and the interface version before using it, otherwise it keeps the bundled engine. A new engine is activated at the next launch, never during an activity. The current engine version is shown in Settings ("Réglages" > "À propos").

What an engine update can and cannot do: it only adds or fixes maths exercises (questions, answer checking, corrections). It does not change the app's purpose, screens or features, does not add ads, purchases or tracking, and collects no data. It requests no permission. It runs in the same WebView as the app interface, whose own bridge only reaches the local progress database, the system share sheet and file save dialog, and HTTPS requests; nothing else (no contacts, location, photos, health or accounts). Only code signed by us is ever loaded. If you prefer, we can isolate the engine in a frame with no access to that bridge.

How to check: open the app, Settings ("Réglages"): the engine version is shown with a button to look for an update. The rest of the review notes below are unchanged.
