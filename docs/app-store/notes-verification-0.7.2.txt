Version 0.7.2: updates of the exercise engine

The exercises come from MathALÉA, an open-source maths exercise generator maintained by CoopMaths, an association of maths teachers funded by the French Ministry of Education (Direction du numérique pour l'éducation, DNE). Source: https://forge.apps.education.fr/coopmaths/mathalea . Teachers in France and French-speaking Switzerland use it every day, and it changes every day: 795 merge requests were merged in the last 30 days, each one reviewed by a teacher. Most are new exercises or fixes, for example a letter missing from the maths keyboard (https://forge.apps.education.fr/coopmaths/mathalea/-/merge_requests/10188) or an answer line misplaced on phones (https://forge.apps.education.fr/coopmaths/mathalea/-/merge_requests/10189).

Until now, such a fix reached iOS students only with a new App Store version, often weeks later. Meanwhile an exercise could reject a correct answer, which misleads a student. Teachers and parents trust us to give correct exercises, and the Ministry funds us for that.

From 0.7.2, the app can download a newer build of its exercise engine:
- JavaScript and CSS only, run by WebKit in the app's WKWebView (Program License Agreement 3.3.1(B)); no native code.
- Published by us over HTTPS in the app's own open-source repository: https://forge.apps.education.fr/coopmaths/mathalea-mobile/-/tree/main/releases/moteur
- The announcement file is signed with our Ed25519 key. The app checks the signature, the size and SHA-256 of the archive and the interface version; otherwise it keeps the bundled engine.
- A new engine is used from the next launch, never during an activity.

An engine update only adds or fixes maths exercises: questions, answer checking, corrections. It does not change the app's purpose, screens or features, adds no ads, purchases or tracking, collects no data and requests no permission. It runs in the same WebView as the app interface, whose bridge only gives access to the local progress database, the share sheet, the file save dialog and HTTPS requests (no contacts, location, photos, health or accounts). Only code signed by us is loaded. If you prefer, we can isolate the engine in a frame with no access to this bridge.

To check: Settings ("Réglages"), "À propos" shows the engine version and a button to look for an update.
